# Uber Ride Analytics Dashboard

## Overview
Interactive Uber ride analysis dashboard built using Power BI.

## Dataset source
https://www.kaggle.com/datasets/yashdevladdha/uber-ride-analytics-dashboard/data?select=ncr_ride_bookings.csv

## Tools Used
- Excel
- Power BI
- DAX

## Data Preparation
• Removed unnecessary columns
• Handled missing values using averages and categories
• Corrected data types
• Created Month, Hour and Time Slot derived columns
• Built KPI summary tables
• Performed EDA using Pivot Tables

## Features
- Data Cleaning
- KPI Analysis
- Dashboard Creation
- Interactive Slicers
- Business Insights

## Key Insights
- Peak booking hour was 6 PM
- Completion rate reached 62%
- Auto generated highest revenue
- UPI was preferred payment method
